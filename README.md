# Syqopat

Systems & security developer building Windows process monitors, malware detection heuristics, and automation tools.

### 🛡️ Security & Systems

- [**basic_infostealer_detector**](https://github.com/Syqopat/basic_infostealer_detector) — Low-level Windows process and persistence auditor.
- [**RAT-DETECT**](https://github.com/Syqopat/RAT-DETECT) — Security utility for detecting remote access trojans.
- [**TCPVIEW-PROJECT**](https://github.com/Syqopat/TCPVIEW-PROJECT) — Real-time network socket, process monitor, and connection tracer.
- [**contribution-farm**](https://github.com/Syqopat/contribution-farm) — Automated contribution engine with dynamic randomizer and Windows Event Log telemetry.
- [**Sypec**](https://github.com/Syqopat/Sypec) — Minecraft network protocol utility plugin.

### 🎮 Engines & Graphics

- [**GAME-MOTOR**](https://github.com/Syqopat/GAME-MOTOR) — Electron-based desktop modular game engine editor.
- [**RUBIKS-CUBE**](https://github.com/Syqopat/RUBIKS-CUBE) — Interactive 3D Three.js Rubik's Cube solver and scrambler.
- [**FIRST**](https://github.com/Syqopat/FIRST) — 2D Pygame platformer engine with modular scene management.

### 🛠️ Stack & Tooling

- **Languages:** C++, Python, JavaScript, TypeScript, Java
- **Systems:** Win32 API, Windows Internals, Sockets & Network Protocols, Linux
- **Frameworks & Tools:** Electron, Three.js, Git, GitHub Actions
